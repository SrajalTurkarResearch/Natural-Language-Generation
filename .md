## 🌱 Preliminary Foundations: Understanding NLG and the Need for Model Compression

### What is NLG?

**Natural Language Generation (NLG)** is a branch of artificial intelligence where computers create text that sounds like it was written by humans.  
Examples include:

- Chatbots answering questions
- Systems writing news reports or summaries
- Predictive text that completes your sentences

These systems use **neural networks**, which are collections of small computing units called _neurons_. Each connection between neurons has a _weight_ — a number that determines how strongly one neuron affects another.

### Transformers: The Core of Modern NLG

Modern NLG models like **GPT (Generative Pre-trained Transformer)** use a special kind of neural network called a **transformer**.  
Transformers are very good at handling sequences, such as words in a sentence.

Example:

> If a model sees “The cat sat on the \_\_\_”, it should predict “mat”.

Training process:

1. The model guesses the next word.
2. We calculate how wrong it is (using a _loss function_).
3. The model adjusts its weights to improve.

Loss function (cross-entropy):

\[
L = - \sum (y_i \times \log(\hat{y_i}))
\]

Where:

- \( y_i \): the correct answer (1 for correct word, 0 for others)
- \( \hat{y_i} \): model’s predicted probability for each word

---

### Why Compress Models?

Large NLG models (like GPT) can have **billions of parameters** (weights).  
These models are:

- Powerful, but **slow and memory-heavy**
- Expensive to train and deploy
- Unsuitable for small devices (like phones)

**Model compression** helps make them smaller and faster while keeping their intelligence.  
The three main techniques are:

1. **Quantization** – reducing number precision
2. **Pruning** – removing unnecessary parts
3. **Distillation** – teaching a smaller model to mimic a large one

Together, they make AI more efficient, eco-friendly, and accessible.

## ⚙️ Section 1: Quantization in NLG

### What Is Quantization?

Quantization converts _high-precision_ numbers in a model (like 32-bit floats) into _lower-precision_ ones (like 8-bit integers).

**Analogy:**  
Packing your suitcase tightly — same clothes, less space.

In neural networks:

- **Weights** = connections between neurons
- **Activations** = neuron outputs

| Type    | Bit-width | Range          | Example  |
| ------- | --------- | -------------- | -------- |
| Float32 | 32-bit    | High precision | 3.141592 |
| Int8    | 8-bit     | –128 to 127    | 3 or –7  |

**Benefits:**  
✅ Smaller model size  
✅ Faster computation  
✅ Lower energy use

---

### Quantization Theory: Step by Step

A typical neural operation is:

\[
Y = W \times X + b
\]

Where \(W\) = weights, \(X\) = inputs, and \(b\) = bias.  
Quantization maps these floating-point numbers to smaller integer ranges while keeping performance close.

---

### Example: Uniform Affine Quantization

Weights: **1.2, 3.7, –0.5**  
Min = –0.5, Max = 3.7

1. **Scale (s):**
   \[
   s = \frac{max - min}{2^b - 1}
   \]
   For 8-bit: \( s = (3.7 - (-0.5)) / 255 = 4.2 / 255 = 0.01647 \)

2. **Zero Point (z):**
   \[
   z = round(-min / s) = 0.5 / 0.01647 ≈ 30
   \]

3. **Quantize (q):**
   \[
   q(T) = clip(round(T/s + z), 0, 255)
   \]

   - 1.2 → 103
   - 3.7 → 255
   - –0.5 → 0

4. **Dequantize:**
   \[
   \hat{T} = s \times (q(T) - z)
   \]
   - 103 → 1.202 (error ≈ 0.002)

**Quantization Error:**
\[
E = s^2 / 12 ≈ 0.00000188
\]

---

### Training Note

Quantization is not differentiable.  
To train, we use a _straight-through estimator (STE)_:

\[
\frac{\partial q(T)}{\partial T} = 1
\]
This allows gradients to pass through as if quantization didn’t exist.

---

### Types of Quantization

| Type                                  | When Applied              | Description                                    |
| ------------------------------------- | ------------------------- | ---------------------------------------------- |
| **Post-Training Quantization (PTQ)**  | After training            | Simple, may slightly reduce accuracy           |
| **Quantization-Aware Training (QAT)** | During training           | Simulates quantization noise during learning   |
| **Mixed Precision**                   | During training/inference | Uses different bit-widths for different layers |

**Example:**  
A model predicting “The sky is blue” remains ~99% accurate after quantization while shrinking from 1 GB → 250 MB.

---

### Real-World Applications

- **BERT on mobile** – faster offline search
- **Healthcare devices** – quantized AI for patient privacy
- **Research** – understanding robustness under quantization

---

### Challenges & Solutions

| Problem                        | Solution                       |
| ------------------------------ | ------------------------------ |
| Accuracy loss at low bit-width | Fine-tune after quantization   |
| Outliers dominate scaling      | Use per-channel quantization   |
| Hardware mismatch              | Use INT8-friendly accelerators |

---

### Advanced Research

- **Non-uniform quantization:** Variable step sizes
- **4-bit quantization:** State-of-the-art for LLMs
- **Learned quantization:** Learn scale and zero-point during training

## 🌿 Section 2: Pruning in NLG

### What Is Pruning?

**Pruning** means removing parts of a neural network that don’t contribute much — like trimming a tree’s dead branches.

You can remove:

- Small or unimportant **weights**
- Whole **neurons** or **attention heads**
- Even **entire layers**

The goal: make the model smaller and faster with minimal performance loss.

---

### Example: Magnitude Pruning

Weights: **0.1, 0.8, –0.3, 0.05**

1. Take absolute values: 0.1, 0.8, 0.3, 0.05
2. Sort: 0.05, 0.1, 0.3, 0.8
3. Prune 50% (threshold = 0.2):  
   → Remaining: **0, 0.8, –0.3, 0**

Sparsity = 2/4 = **50%**

Approximate loss change (Taylor expansion):

\[
\Delta L ≈ g_w \Delta w + 0.5H(\Delta w)^2
\]
\[
0.2(-0.1) + 0.5(0.1)^2 = -0.015
\]

So pruning slightly increases loss but simplifies the network.

---

### Types of Pruning

| Type             | Description               | Pros         | Cons               |
| ---------------- | ------------------------- | ------------ | ------------------ |
| **Unstructured** | Remove individual weights | Flexible     | Hard for hardware  |
| **Structured**   | Remove neurons or layers  | Real speedup | Risky for accuracy |
| **Dynamic**      | Prune during training     | Adaptive     | Complex            |

---

### Typical Workflow

1. Train the full model
2. Compute importance scores
3. Prune less important parts
4. Fine-tune to recover accuracy

---

### Real-World Examples

- **GPT Head Pruning:** Up to 50% attention heads removed
- **Sparse Transformers:** Efficient summarization and translation

---

### Challenges & Solutions

| Problem                  | Solution                                        |
| ------------------------ | ----------------------------------------------- |
| Accuracy loss            | Gradual or iterative pruning                    |
| Inefficient hardware use | Structured pruning                              |
| Loss of language quality | Rewind to earlier checkpoint before fine-tuning |

---

### Research Directions

- **Dynamic pruning:** Model adjusts structure at runtime
- **Bias reduction:** Prune bias-related neurons
- **Lottery Ticket Hypothesis:** Find smaller subnetworks that perform well independently

## 🔥 Section 3: Distillation in NLG

### What Is Knowledge Distillation?

**Knowledge distillation (KD)** trains a small **student model** to mimic a large **teacher model**.  
The student learns both the answers _and_ the teacher’s reasoning.

**Analogy:**  
A teacher doesn’t just say “correct answer,” but also explains _why_.

---

### How It Works

1. Train a large **teacher** model.
2. Use it to produce “soft targets” (probability distributions).
3. Train a smaller **student** model to match them.

Mathematically:

\[
L\_{KD} = \tau^2 \times KL(P_T^\tau \| P_S^\tau)
\]

Where:

- \( P_T^\tau \): teacher’s softened probabilities
- \( P_S^\tau \): student’s probabilities
- \( \tau \): temperature
- \( KL \): Kullback–Leibler divergence

Higher temperature \( \tau \) makes the distribution smoother, helping learning.

---

### Example

Teacher:

> “blue”: 0.9, “green”: 0.1

Student:

> “blue”: 0.6, “green”: 0.4

Distillation nudges the student toward the teacher’s confidence levels.

---

### Types of Distillation

| Type                           | Description                                  |
| ------------------------------ | -------------------------------------------- |
| **Logit Distillation**         | Learn from teacher’s soft probabilities      |
| **Feature Distillation**       | Match hidden layer activations               |
| **Self-Distillation**          | Teach future self (retrain smaller versions) |
| **Multi-Teacher Distillation** | Learn from several teachers                  |

---

### Real-World Examples

- **DistilBERT** – 40% smaller, 97% performance of BERT
- **TinyGPT** – Distilled GPT variant for mobile
- **Privacy-preserving KD** – Distill knowledge without exposing private data

---

### Challenges & Solutions

| Problem            | Fix                                         |
| ------------------ | ------------------------------------------- |
| Student too small  | Use intermediate teacher layers as guidance |
| Teacher bias       | Train with multiple teachers                |
| Temperature tuning | Adjust empirically during training          |

---

### Advanced Research

- **Cross-lingual KD:** Transfer knowledge across languages
- **Data-free KD:** Use synthetic data for distillation
- **Ethical KD:** Filter out toxic or biased behaviors

## 🌎 Section 4: Integrating Techniques and Research Horizons

### Combining Quantization, Pruning, and Distillation

Modern models combine all three methods for maximum compression:

1. **Prune → Distill → Quantize**
   - Remove redundancy
   - Transfer knowledge
   - Compress numbers

Results:  
10×–30× smaller models, almost same performance.

---

### Example Pipeline

| Step | Action                    | Benefit                |
| ---- | ------------------------- | ---------------------- |
| 1    | Prune 40% of weights      | Removes redundancy     |
| 2    | Distill from full teacher | Retains core knowledge |
| 3    | Quantize to 8-bit         | Faster, smaller model  |

Outcome:  
A **6× smaller, 3× faster** NLG model with minimal quality loss.

**Future directions:**
